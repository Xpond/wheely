# Security

wheely patches Omarchy's shell with `sudo` and replaces the lock screen, so please report
security problems privately: use
[Report a vulnerability](https://github.com/Xpond/wheely/security/advisories/new)
instead of an issue or pull request.

Include what you did, what happened, and the output of `omarchy-version`. Fixes land on
`main`; there are no maintained older versions.
