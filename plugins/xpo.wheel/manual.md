# Wheely manual

Everything in the wheel is searchable: panels, the Omarchy menu, keybindings, apps,
windows, themes, fonts, settings, files with `/`, and this manual. Just type.

Type `help` in the wheel to search this manual: every row below is a search row.
Add a word to narrow it, like `help files` or `help rename`. Enter on any row shows
the whole manual on one screen, where typing filters rows, Ctrl+T pins it as
a window, and Esc goes back. Backspace also goes back when the filter is empty.

## Wheel

| Key | What it does |
|---|---|
| `SUPER+A` | open or close the wheel |
| `SUPER+W` | close it and what it opened |
| `↑` `↓` | jump to that compass point |
| `←` `→` | step around the ring |
| `Tab` `Shift+Tab` | step the ring, or the results |
| `Enter` | run, or open a submenu |
| `Backspace` | back to the ring you came from, or to the wheel |
| `Esc` | clear, back a ring, then close |
| mouse | flick or click a slice |

| Key | What it does |
|---|---|

| `↑` `↓` `Tab` `Shift+Tab` | choose |

| `→` | open a submenu |
| `←` `Backspace` | back from a submenu |
| `Del` | trash; press again to confirm |

## Settings

Type `wheely settings`; Enter changes a setting without closing the wheel.
Esc or Backspace with an empty filter returns from a setting.

| Setting | What it does |
|---|---|
| Wheely shortcut | Enter, then a combo with SUPER |
| Wallpaper pause | Enter, then a combo for Wheelie or Tidal |
| Wheely ring | Enter to edit the ring |
| Backdrop | Enter, then ←/→ for the blur |
| Centered panels | Enter: centered or by the bar |
| Searched folders | more folders for / to search |
| Skipped folders | folders / never searches |
| Wheely history | your past picks |
| Forget picks | Enter twice to reset picks |
| `Del` | remove an entry from a list |

## Ring editor

Opened by the Wheely ring setting; every change is saved as it is made.

| Key | What it does |
|---|---|
| type anything | find a slice; Enter adds it |
| `Del` | remove the slice |
| `Shift+←` `Shift+→` | move the slice |
| `Ctrl+R` | reset to the bar; press twice |
| `Esc` `Backspace` | done |
